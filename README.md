# D2L Learning Notes / 《动手学深度学习》学习笔记

Personal bilingual (EN/ZH) study notes for [Dive into Deep Learning](https://d2l.ai/).

Each chapter contains structured notes in three parts:
1. **Intuition** — zero-formula explanations with analogies and walkthroughs
2. **Math** — rigorous derivations with numbered equations
3. **Code** — implementation notes comparing scratch vs. framework approaches
